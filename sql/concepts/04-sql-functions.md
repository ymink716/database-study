## 1. SQL 함수의 종류

**SQL 함수**는 데이터를 입력받아 계산하거나 가공한 결과를 반환하는 기능이다. 문자열의 일부를 추출하거나, 날짜를 계산하고, 여러 행의 데이터를 합산할 때 사용할 수 있다.

함수는 결과를 계산하는 범위에 따라 크게 두 종류로 나뉜다.

| 구분                              | 설명                                           | 예시                                      |
| --------------------------------- | ---------------------------------------------- | ----------------------------------------- |
| 단일 행 함수(Single Row Function) | 각 행의 값을 처리해 행마다 결과를 반환한다.    | `UPPER`, `ROUND`, `ADD_MONTHS`, `TO_CHAR` |
| 그룹 함수(Aggregate Function)     | 여러 행의 값을 모아 하나의 집계 결과를 만든다. | `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`       |

<br>

## 2. 문자 함수

문자 함수는 문자열의 대소문자를 바꾸거나 일부를 추출하고, 길이를 확인하거나 문자를 채우고 바꾸는 데 사용한다.

### 대소문자 변환과 문자열 추출

| 함수      | 역할                              | 예제 표현식                | 결과         |
| --------- | --------------------------------- | -------------------------- | ------------ |
| `UPPER`   | 영문자를 대문자로 변환            | `UPPER('Oracle SQL')`      | `ORACLE SQL` |
| `LOWER`   | 영문자를 소문자로 변환            | `LOWER('Oracle SQL')`      | `oracle sql` |
| `INITCAP` | 각 단어의 첫 글자를 대문자로 변환 | `INITCAP('oracle sql')`    | `Oracle Sql` |
| `CONCAT`  | 두 문자열을 연결                  | `CONCAT('ORA', 'CLE')`     | `ORACLE`     |
| `SUBSTR`  | 지정한 위치부터 문자열 일부 추출  | `SUBSTR('DATABASE', 1, 4)` | `DATA`       |
| `LENGTH`  | 문자열의 문자 수 반환             | `LENGTH('홍길동')`         | `3`          |

```sql
SELECT SUBSTR('DATABASE', -4, 4) AS RESULT
FROM DUAL;
-- 결과: BASE
```

`SUBSTR(문자열, 시작 위치, 길이)`에서 시작 위치는 1부터 세며, 음수를 주면 문자열 끝에서부터 위치를 계산한다. 길이를 생략하면 시작 위치부터 끝까지 가져온다.

```sql
SELECT NAME,
       UPPER(TITLE) AS TITLE_UPPER,
       SUBSTR(NAME, 1, 1) AS FIRST_CHAR,
       LENGTH(NAME) AS NAME_LENGTH
FROM S_EMP;
```

직원별로 직책을 대문자로 변환하고, 이름의 첫 글자와 이름 길이를 조회한다. `TITLE`에 한글이 있다면 `UPPER`를 적용해도 한글 부분은 그대로 표시된다.

(문자열 연결은 앞서 배운 `||` 연산자로도 가능하다. `CONCAT`은 두 값을 연결하고, `||`는 여러 값을 이어 붙이기에 편리하다.)

### 문자 채우기와 제거

| 함수    | 역할                                    | 예제 표현식           | 결과     |
| ------- | --------------------------------------- | --------------------- | -------- |
| `LPAD`  | 왼쪽에 문자를 채워 지정한 길이로 만듦   | `LPAD('SQL', 6, '*')` | `***SQL` |
| `RPAD`  | 오른쪽에 문자를 채워 지정한 길이로 만듦 | `RPAD('SQL', 6, '*')` | `SQL***` |
| `LTRIM` | 왼쪽에서 지정한 문자들을 제거           | `LTRIM('XXABX', 'X')` | `ABX`    |
| `RTRIM` | 오른쪽에서 지정한 문자들을 제거         | `RTRIM('ABXX', 'X')`  | `AB`     |

`LPAD`, `RPAD`의 두 번째 인자는 **최종 문자열 길이**다. `LTRIM`, `RTRIM`은 문자열 안의 문자를 전부 지우는 것이 아니라, 지정한 쪽 끝에서부터 조건에 맞는 문자를 제거한다.

### 문자 변환과 치환

| 함수        | 역할                                  | 예제 표현식                    | 결과    |
| ----------- | ------------------------------------- | ------------------------------ | ------- |
| `TRANSLATE` | 지정한 문자를 한 글자씩 대응시켜 바꿈 | `TRANSLATE('AABBA', 'B', 'C')` | `AACCA` |
| `REPLACE`   | 지정한 문자열을 다른 문자열로 바꿈    | `REPLACE('AABBA', 'BB', 'C')`  | `AACA`  |

**`TRANSLATE`는 문자 단위**, **`REPLACE`는 문자열 단위**로 치환한다는 차이가 있다.

## 3. 숫자 함수

숫자 함수는 숫자를 반올림하거나 버리고, 나머지·거듭제곱·제곱근 등을 구하는 데 사용한다.

| 함수    | 역할                                               | 예제 표현식        | 결과    |
| ------- | -------------------------------------------------- | ------------------ | ------- |
| `ROUND` | 지정한 자리에서 반올림                             | `ROUND(35.735, 2)` | `35.74` |
| `TRUNC` | 지정한 자리 아래를 버림                            | `TRUNC(35.735, 2)` | `35.73` |
| `MOD`   | 나눗셈의 나머지                                    | `MOD(7, 2)`        | `1`     |
| `POWER` | 거듭제곱                                           | `POWER(3, 2)`      | `9`     |
| `SQRT`  | 제곱근                                             | `SQRT(25)`         | `5`     |
| `SIGN`  | 숫자의 부호 판단                                   | `SIGN(-15)`        | `-1`    |
| `CHR`   | 데이터베이스 문자 집합에서 해당 코드값의 문자 반환 | `CHR(65)`          | `A`     |

`SIGN`은 양수면 `1`, 0이면 `0`, 음수면 `-1`을 반환한다. `CHR`은 숫자를 입력받지만 결과는 문자이므로 용도를 함께 기억하면 좋다.

`ROUND(숫자, 자리수)`와 `TRUNC(숫자, 자리수)`에서 자리수가 양수면 소수점 아래를, 음수면 정수 부분을 기준으로 계산한다.

```sql
SELECT ROUND(1567, -2) AS ROUNDED,
       TRUNC(1567, -2) AS TRUNCATED
FROM DUAL;
-- 결과: ROUNDED = 1600, TRUNCATED = 1500
```

```sql
SELECT NAME, SALARY,
       ROUND(SALARY / 12, 2) AS SALARY_DIV_12
FROM S_EMP;
```

각 직원의 `SALARY`를 12로 나눈 뒤 소수 둘째 자리까지 반올림해 표시한다. 원본 급여는 바뀌지 않는다.

## 4. 날짜 함수와 날짜 연산

Oracle의 `DATE`는 날짜뿐 아니라 시·분·초도 저장한다. 날짜 함수로 월말을 구하거나 개월 수를 계산하고, 날짜를 월·연도 단위로 반올림하거나 잘라낼 수 있다.

| 함수             | 역할                                          | 예제                                                                                       | 결과                  |
| ---------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------ | --------------------- |
| `SYSDATE`        | 현재 날짜와 시간 반환                         | `SYSDATE`                                                                                  | 실행 시점의 날짜·시간 |
| `LAST_DAY`       | 해당 월의 마지막 날                           | `LAST_DAY(TO_DATE('2024-02-10', 'YYYY-MM-DD'))`                                            | `2024-02-29`          |
| `MONTHS_BETWEEN` | 두 날짜 사이의 개월 수(첫째 날짜 − 둘째 날짜) | `MONTHS_BETWEEN(TO_DATE('2026-03-01', 'YYYY-MM-DD'), TO_DATE('2026-01-01', 'YYYY-MM-DD'))` | `2`                   |
| `ADD_MONTHS`     | 날짜에 개월 수를 더함                         | `ADD_MONTHS(TO_DATE('2026-01-10', 'YYYY-MM-DD'), 2)`                                       | `2026-03-10`          |
| `ROUND`          | 날짜를 지정한 단위로 반올림                   | `ROUND(TO_DATE('2026-05-16', 'YYYY-MM-DD'), 'MM')`                                         | `2026-06-01`          |
| `TRUNC`          | 날짜를 지정한 단위의 시작으로 자름            | `TRUNC(TO_DATE('2026-05-16', 'YYYY-MM-DD'), 'YYYY')`                                       | `2026-01-01`          |

날짜 결과는 표에서 이해하기 쉽게 `YYYY-MM-DD` 형식으로 적었다. 실제 조회 화면의 표시 형식은 설정에 따라 다를 수 있으며, `TO_CHAR`로 원하는 형식을 지정할 수 있다.

```sql
SELECT TO_CHAR(LAST_DAY(TO_DATE('2024-02-10', 'YYYY-MM-DD')),
               'YYYY-MM-DD') AS MONTH_END
FROM DUAL;
-- 결과: 2024-02-29
```

날짜에 숫자를 더하거나 빼면 일 단위로 계산하며, `DATE`끼리 빼면 날짜 차이가 일(day) 단위의 숫자로 나온다.

```sql
SELECT TO_CHAR(TO_DATE('2026-03-10', 'YYYY-MM-DD') + 7,
               'YYYY-MM-DD') AS AFTER_7_DAYS,
       TO_DATE('2026-03-10', 'YYYY-MM-DD')
       - TO_DATE('2026-03-01', 'YYYY-MM-DD') AS DAY_DIFF
FROM DUAL;
-- 결과: AFTER_7_DAYS = 2026-03-17, DAY_DIFF = 9
```

## 5. 형 변환 함수

형 변환 함수는 숫자나 날짜를 원하는 형식의 문자열로 보여주거나, 문자열을 숫자·날짜 타입으로 바꿀 때 사용한다.

| 함수        | 변환 방향   | 예제 표현식                                                  | 결과                       |
| ----------- | ----------- | ------------------------------------------------------------ | -------------------------- |
| `TO_CHAR`   | 숫자 → 문자 | `TO_CHAR(350000, 'FM999,999')`                               | `'350,000'`                |
| `TO_CHAR`   | 날짜 → 문자 | `TO_CHAR(TO_DATE('2026-03-05', 'YYYY-MM-DD'), 'YYYY/MM/DD')` | `'2026/03/05'`             |
| `TO_NUMBER` | 문자 → 숫자 | `TO_NUMBER('1234')`                                          | 1234                       |
| `TO_DATE`   | 문자 → 날짜 | `TO_DATE('2026-03-05', 'YYYY-MM-DD')`                        | 2026년 3월 5일의 `DATE` 값 |

### 자주 사용하는 형식 요소

| 숫자 형식 | 의미                        | 날짜 형식            | 의미     |
| --------- | --------------------------- | -------------------- | -------- |
| `9`       | 숫자 자리 표시              | `YYYY`, `YY`         | 연도     |
| `0`       | 비어 있는 자리를 0으로 채움 | `MM`, `MON`, `MONTH` | 월       |
| `,`       | 천 단위 구분                | `DD`                 | 일       |
| `.`       | 소수점                      | `DAY`, `DY`          | 요일     |
| `$`, `L`  | 달러·지역 통화 기호         | `HH24`, `MI`, `SS`   | 시·분·초 |

숫자 형식의 `FM`은 불필요한 앞뒤 공백을 없애는 형식 옵션이다.

```sql
SELECT TO_CHAR(123, 'FM00000') AS NUMBER_TEXT,
       TO_NUMBER('1234') + 10 AS NUMBER_VALUE
FROM DUAL;
-- 결과: NUMBER_TEXT = '00123', NUMBER_VALUE = 1244
```

```sql
SELECT TO_CHAR(
    TO_DATE('2026-03-05 15:30:00', 'YYYY-MM-DD HH24:MI:SS'),
    'YYYY-MM-DD HH:MI AM',
    'NLS_DATE_LANGUAGE=ENGLISH'
) AS RESULT
FROM DUAL;
-- 결과: 2026-03-05 03:30 PM
-- AM, PM, A.M., P.M. 오전 또는 오후 표시
```

`TO_DATE`로 만든 값은 문자처럼 보이더라도 실제로는 날짜 타입이고, `TO_CHAR`로 변환한 값은 문자열이다. **표시 형식과 데이터 타입은 구분해서 생각해야 한다.**

## 6. 함수 중첩

함수는 다른 함수의 결과를 입력값으로 사용할 수 있다. **안쪽 함수부터 실행되고 바깥쪽 함수가 그 결과를 처리한다.**

```sql
SELECT TO_CHAR(ROUND(1234.567, 2), 'FM9,999.00') AS RESULT
FROM DUAL;
-- 결과: 1,234.57
```

1. `ROUND(1234.567, 2)` → `1234.57`

2. `TO_CHAR(1234.57, 'FM9,999.00')` → `'1,234.57'`

이처럼 계산한 숫자를 원하는 출력 형식의 문자열로 바꾸는 작업에 자주 사용한다.

<br>

## 7. 그룹 함수

그룹 함수는 여러 행의 값을 모아 **개수, 합계, 평균, 최솟값, 최댓값** 등을 계산한다. `GROUP BY` 없이 사용하면 조회 대상 전체를 하나의 그룹으로 집계한다.

| 함수          | 역할                                        |
| ------------- | ------------------------------------------- |
| `COUNT(*)`    | `NULL` 여부와 관계없이 행의 개수를 센다.    |
| `COUNT(컬럼)` | 해당 컬럼이 `NULL`이 아닌 행의 개수를 센다. |
| `SUM`         | 합계                                        |
| `AVG`         | 평균                                        |
| `MIN`         | 최솟값                                      |
| `MAX`         | 최댓값                                      |
| `STDDEV`      | 표준편차                                    |
| `VARIANCE`    | 분산                                        |

`COUNT(*)`를 제외한 위 집계 함수는 계산할 때 `NULL` 값을 제외한다. 예를 들어 `AVG(SALARY)`는 급여가 `NULL`인 직원은 제외하고 평균을 계산한다.

### 고정값으로 결과 확인하기

별도 테이블을 생성하지 않고 `10`, `20`, `30` 세 값을 집계하는 예제다.

```sql
WITH NUMS AS (
    SELECT 10 AS N FROM DUAL
    UNION ALL SELECT 20 FROM DUAL
    UNION ALL SELECT 30 FROM DUAL
)
SELECT COUNT(*) AS CNT,
       SUM(N) AS TOTAL,
       AVG(N) AS AVERAGE,
       MIN(N) AS MIN_VALUE,
       MAX(N) AS MAX_VALUE,
       STDDEV(N) AS STD_DEV,
       VARIANCE(N) AS VAR_VALUE
FROM NUMS;
```

| CNT | TOTAL | AVERAGE | MIN_VALUE | MAX_VALUE | STD_DEV | VAR_VALUE |
| --- | ----- | ------- | --------- | --------- | ------- | --------- |
| 3   | 60    | 20      | 10        | 30        | 10      | 100       |

```sql
SELECT COUNT(*) AS EMP_COUNT,
       COUNT(SALARY) AS SALARY_COUNT,
       ROUND(AVG(SALARY), 2) AS AVG_SALARY,
       MAX(SALARY) AS MAX_SALARY
FROM S_EMP;
```

직원 전체 수, 급여가 입력된 직원 수, 평균 급여, 최고 급여를 **한 행**으로 조회한다.
