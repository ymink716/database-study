## 1. SQL 명령어의 기본 분류

SQL은 데이터를 조회하거나 변경하는 것뿐 아니라 테이블을 만들고, 권한을 관리하고, 변경한 내용을 확정하는 데도 사용한다. **어떤 작업을 하는지**에 따라 명령어를 구분할 수 있다.

| 분류                | 역할                                                    | 주요 명령어                                                |
| ------------------- | ------------------------------------------------------- | ---------------------------------------------------------- |
| Query (데이터 조회) | 필요한 데이터를 검색한다.                               | `SELECT`                                                   |
| DML (데이터 조작)   | 테이블에 저장된 데이터를 추가·수정·삭제한다.            | `INSERT`, `UPDATE`, `DELETE`                               |
| DDL (데이터 정의)   | 테이블 등 데이터베이스 객체의 구조를 만들거나 변경한다. | `CREATE`, `ALTER`, `DROP`, `TRUNCATE`, `RENAME`, `COMMENT` |
| TCL (트랜잭션 제어) | 데이터 변경 내용을 확정하거나 되돌린다.                 | `COMMIT`, `ROLLBACK`, `SAVEPOINT`                          |
| DCL (데이터 제어)   | 사용자에게 권한을 부여하거나 회수한다.                  | `GRANT`, `REVOKE`                                          |

특히 **DML은 테이블 안의 데이터를 바꾸는 명령어**, **DDL은 테이블 자체의 구조를 다루는 명령어**라는 차이를 기억하면 구분하기 쉽다.

<br>

## 2. 테이블 명명 규칙

테이블과 컬럼에는 SQL에서 구별할 수 있는 이름을 붙여야 한다. Oracle에서 일반적으로 사용하는 **큰따옴표 없는 이름**의 규칙은 다음과 같다.

- 이름은 문자로 시작하며, 문자·숫자·밑줄(`_`)·달러 기호(`$`)·샵(`#`)을 사용할 수 있다. 일반적으로는 문자·숫자·밑줄을 사용하는 편이 읽기 쉽다.
- `SELECT`, `TABLE` 같은 SQL 예약어는 이름으로 사용할 수 없다.
- 같은 스키마에서 동일한 종류의 테이블 이름을 중복해서 사용할 수 없다. 일부 다른 객체와도 이름이 겹치면 안 된다.
- 큰따옴표 없이 작성한 이름은 대소문자를 구별하지 않는다. 예를 들어 `S_EMP`와 `s_emp`는 같은 이름으로 처리된다.
- 일반적인 테이블·컬럼 이름은 최대 128바이트까지 사용할 수 있지만, Oracle의 호환성 설정에 따라 제한이 달라질 수 있다.

이름은 문법에 맞는 것뿐 아니라 **어떤 데이터를 저장하는지 알 수 있게** 짓는 것이 좋다. 예를 들어 `M`보다 `STUDY_MEMBER`, `N`보다 `MEMBER_NAME`이 의미를 파악하기 쉽다.

## 3. 데이터 타입(Data Type)

테이블을 만들 때는 각 컬럼에 **어떤 종류의 값을 저장할지** 데이터 타입을 지정한다. 데이터 타입에 따라 저장할 수 있는 값과 크기, 처리 방식이 달라진다.

### 주요 데이터 타입

| 데이터 타입        | 설명                                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- |
| `VARCHAR2(n)`      | 길이가 달라질 수 있는 문자열을 저장한다.                                                                         |
| `CHAR(n)`          | 정해진 길이의 문자열을 저장한다. 짧은 값은 남는 자리를 공백으로 채운다.                                          |
| `NUMBER`           | 숫자를 저장한다.                                                                                                 |
| `NUMBER(p, s)`     | 전체 유효 자릿수(`p`)와 소수점 이하 자릿수(`s`)를 지정한다.                                                      |
| `DATE`             | 날짜뿐 아니라 시·분·초까지 저장한다.                                                                             |
| `RAW(n)`           | 문자로 해석하지 않는 이진 데이터를 저장한다. (바이너리)                                                          |
| `LONG`, `LONG RAW` | 긴 문자 데이터와 이진 데이터를 저장하던 타입으로, 새로 설계할 때는 보통 `CLOB`, `BLOB` 등의 LOB 타입을 사용한다. |

**`VARCHAR2`와 `CHAR`의 차이**는 문자열 길이를 다루는 방식에 있다. 이름처럼 길이가 달라지는 데이터에는 주로 `VARCHAR2`를 사용하고, 고정된 길이가 필요한 경우에는 `CHAR`를 고려한다.

`NUMBER(7, 2)`는 전체 유효 자릿수가 7자리이고, 그중 소수점 아래 2자리를 사용한다는 뜻이다. `VARCHAR2(30 CHAR)`처럼 `CHAR`를 명시하면 길이를 바이트가 아닌 문자 수 기준으로 지정할 수 있다.

### 테이블 생성 예제

```sql
CREATE TABLE EMP (
    ID        NUMBER(5) PRIMARY KEY,
    NAME      VARCHAR2(30 CHAR) NOT NULL,
    SALARY    NUMBER(9, 2),
    JOIN_DATE DATE DEFAULT SYSDATE
);
```

`EMP` 테이블에는 직원 번호, 이름, 급여, 입사일을 저장한다. `DEFAULT SYSDATE`를 지정한 `JOIN_DATE`는 값을 따로 입력하지 않으면 현재 날짜와 시간을 기본값으로 사용한다.

## 4. DML: INSERT, UPDATE, DELETE

**DML(Data Manipulation Language)**은 테이블에 저장된 데이터를 추가하거나, 기존 값을 수정하거나, 삭제할 때 사용하는 명령어다. 테이블 구조를 바꾸는 것이 아니라 **테이블 안의 행(Row)을 다룬다**는 점이 핵심이다.

### INSERT: 데이터 추가

`INSERT`는 테이블에 새로운 행을 추가한다.

```sql
INSERT INTO EMP (ID, NAME, SALARY)
VALUES (1, '홍길동', 3000);
```

- `INTO` 뒤에는 데이터를 넣을 테이블을 지정한다.
- 컬럼 목록과 `VALUES`의 값은 순서대로 대응해야 한다.
- 컬럼 목록을 생략할 수도 있지만, 어떤 컬럼에 값을 넣는지 명확하게 보이도록 작성하는 편이 좋다.
- 예제에서 `JOIN_DATE`를 생략했으므로 테이블에 설정한 기본값(`SYSDATE`)이 사용된다.

### UPDATE: 데이터 수정

`UPDATE`는 이미 저장된 행의 컬럼 값을 변경한다.

```sql
UPDATE EMP
SET SALARY = 3500
WHERE ID = 1;
```

`SET`에서 변경할 값을 지정하고, `WHERE`에서 수정할 행을 선택한다. 조건에 맞는 행이 여러 개라면 여러 행이 한 번에 수정된다.

**`WHERE`를 생략하면 모든 행이 수정 대상이 되므로 주의해야 한다.**

### DELETE: 데이터 삭제

`DELETE`는 테이블에서 행을 삭제한다.

```sql
DELETE FROM EMP
WHERE ID = 1;
```

`WHERE` 조건에 맞는 행만 삭제한다. **`WHERE`를 생략하면 테이블의 모든 행이 삭제 대상**이지만, 테이블 구조는 남아 있다.

### 데이터 변경과 트랜잭션

`INSERT`, `UPDATE`, `DELETE`로 변경한 내용은 트랜잭션으로 관리할 수 있다.

- `COMMIT`: 변경 내용을 확정한다.
- `ROLLBACK`: 아직 확정하지 않은 변경 내용을 되돌린다.

따라서 데이터를 수정하거나 삭제할 때는 `WHERE` 조건을 먼저 확인하고, 변경 결과를 점검한 뒤 확정하는 습관이 중요하다.
